LLMPosture

A behavioural security scanner for large language models. It runs 44 probes against an LLM endpoint and reports where the guardrails give way: prompt injection, system prompt leakage, jailbreaks, encoding bypasses, indirect injection, sensitive data disclosure, excessive agency, and unsafe output handling. Every probe is scored against benign canaries generated for the run, never against real harmful content. Source and full methodology: github.com/RahilSahu/llmposture.

Try it now: built-in demo targets

Two simulated LLM apps run inside this page's scan function. No API key, no external calls. The weak one is deliberately badly guarded; the strict one refuses the probes.

Scan your own endpoint

Any OpenAI-compatible chat completions endpoint works. Pick a provider preset or paste a custom base URL, for example a local Ollama or vLLM server.

How your key is handled: it stays in this browser tab. When you run a scan, the browser sends one probe at a time to the scan function together with the key; the function uses it only to call the provider you chose and never stores or logs it. Nothing is kept after the scan finishes. If you would rather not paste a key into a web page, the same scanner runs locally as a command line tool.

Findings

Method in brief: each probe is sent with a test system prompt that plants fresh canaries (a protected marker token, a fake API key, a fake customer record). A probe fails only when the target outputs a canary, leaks planted content, calls a fake tool without confirmation, or emits unsafe markup carrying the marker. The score is severity-weighted across the probes in the run. A clean score means these probes were resisted; it is not a certification of security.

Authorised use only: scan models and endpoints you own or are explicitly authorised to test, with your own API keys. Probing third-party services outside their terms can get accounts terminated and may be unlawful.
