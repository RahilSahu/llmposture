LLMPosture

A security scanner for large language models. Give it your LLM endpoint URL and it runs 76 probes against it and reports where the guardrails give way: prompt injection, system prompt leakage, jailbreaks, encoding bypasses, indirect injection, sensitive data disclosure, excessive agency, unsafe output handling, and RAG or memory poisoning. Every probe is scored against benign canaries generated for the run, never against real harmful content. Source and full methodology: github.com/RahilSahu/llmposture.

Scan your LLM

Paste the base URL of your endpoint, pick the model, and run the full probe suite against it. OpenAI-compatible chat completions endpoints work out of the box; native adapters cover Anthropic, Google Gemini, and Ollama.

How your key is handled: it stays in this browser tab and is sent only with the scan requests you start. The scan function uses it only to call the endpoint you chose; it is never stored, never logged, and never included in results or downloaded reports. If you would rather not paste a key into a web page, the same scanner runs locally as a command line tool.
Limits of the hosted scanner: it can only reach public endpoints. URLs that resolve to localhost, private, or cloud-metadata addresses are refused. To scan a local model (for example your own Ollama), run LLMPosture locally instead. Scans run in batches inside short-lived serverless functions, so a probe that runs too long comes back as an error rather than a verdict, and a best-effort per-IP rate limit applies to batch scans.

Demo targets

No endpoint of your own? These two simulated LLM apps run inside this page's scan function: no API key, no external calls. The weak one is deliberately badly guarded; the strict one refuses the probes. Demo only, they show the shape of a report, not the posture of a real model.

Method in brief: each probe is sent with a test system prompt that plants fresh canaries (a protected marker token, a fake API key, a fake customer record). A probe fails only when the target outputs a canary, leaks planted content, calls a fake tool without confirmation, or emits unsafe markup carrying the marker. The score is severity-weighted across the probes in the run. A clean score means these probes were resisted; it is not a certification of security.

Authorised use only: scan models and endpoints you own or are explicitly authorised to test, with your own API keys. Probing third-party services outside their terms can get accounts terminated and may be unlawful.
